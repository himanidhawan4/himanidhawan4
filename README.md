      <ul>
        <li><b>🔎 PR Security Analysis:</b> Automatically analyse GitHub Pull Requests</li>
        <li><b>🛡️ SonarQube:</b> Static code quality and security analysis</li>
        <li><b>📦 OSV:</b> Dependency vulnerability scanning</li>
        <li><b>📊 Security Scorecard:</b> Generate an analytical security score</li>
        <li><b>🚦 Security Gates:</b> Block deployment when defined security conditions fail</li>
        <li><b>💡 Error Explanation:</b> Explain why a security issue matters</li>
        <li><b>⚠️ Consequences:</b> Show potential impact of detected vulnerabilities</li>
        <li><b>🔧 Remediation:</b> Provide useful remediation guidance</li>
        <li><b>⚙️ Jenkins:</b> Automate CI/CD workflows</li>
        <li><b>🐳 Docker:</b> Containerize builds and deployment</li>
        <li><b>☁️ AWS:</b> Deploy approved applications to AWS</li>
        <li><b>🔐 Authentication:</b> Secure user authentication</li>
        <li><b>👥 RBAC:</b> Role-Based Access Control</li>
        <li><b>👨‍💼 Admin Approval:</b> Require authorized approval before deployment</li>
        <li><b>📝 Audit History:</b> Track security and deployment activity</li>
      </ul>
